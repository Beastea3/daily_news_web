## 🔬 Research & Science

- [RENDER: Controlling Reader-Facing Evidence in LLM Memory Evaluation](https://arxiv.org/abs/2608.23568)
  - 摘要：RENDER is a benchmark that fixes conversation history while varying the reader-facing artifact (memory entry, summary, typed record, or raw excerpt). It introduces a five-level packet ladder and shows that matched-budget resolved packets beat recency-truncated raw dialogue by 42% on 500 LongMemEval questions across nine models.
  - 来源：ArXiv CS AI (rss.arxiv.org) · 重要性：★★★☆☆

- [ESQ-Bench: A Multi-Tier Enterprise Oracle Benchmark for Evaluating NL2SQL Dialect Generalization](https://arxiv.org/abs/2608.23569)
  - 摘要：ESQ-Bench introduces an Oracle-first NL2SQL benchmark with systematic complexity tiers and silent-divergence evaluation across three enterprise schema complexity levels. It includes six populated schemas (465 tables, 164,682 rows) across Oracle, PostgreSQL, MySQL, and SQL Server, plus 550 gold-validated query pairs.
  - 来源：ArXiv CS AI (rss.arxiv.org) · 重要性：★★★☆☆

- [LLM Agents Perform Controlled Experiments Using Simulation Models](https://arxiv.org/abs/2608.23622)
  - 摘要：A multi-agent framework that enables LLM agents to conduct controlled experiments with scientific simulation models for pharmaceutical process design. The system constructs task representations, designs experiments, executes comparative simulations, and synthesizes evidence-based recommendations for process parameter optimization.
  - 来源：ArXiv CS AI (rss.arxiv.org) · 重要性：★★★☆☆

- [TRACE: Transition-Aware Residual Control for Multi-Objective Materials Discovery](https://arxiv.org/abs/2608.23631)
  - 摘要：TRACE is a transition-aware residual control framework for multi-objective materials discovery with LLM agents. It treats evaluated edits as the basic unit of feedback, enabling local refinement when objectives compete and an edit that improves one property may damage another.
  - 来源：ArXiv CS AI (rss.arxiv.org) · 重要性：★★★☆☆

- [Function-Level Execution Feedback for Code Preference Optimization](https://arxiv.org/abs/2608.23632)
  - 摘要：STEP-KTODER proposes a framework for code preference optimization that defines steps as module-level functions in decomposed multi-function programs. It assigns binary correctness labels via automatically generated unit tests, addressing the lack of a standard notion of a "step" in code generation.
  - 来源：ArXiv CS AI (rss.arxiv.org) · 重要性：★★★☆☆

- [Auditing the Synthetic Memoir: Measuring Scene-Level Confabulation in LLM-Generated Autobiography](https://arxiv.org/abs/2608.23640)
  - 摘要：A first-of-its-kind quantified audit of LLM-generated autobiography against a subject-specific ground-truth corpus. The study found that 354 out of 366 days (96.7%) failed verification when scenes were positively corroborated against an independent corpus, revealing a high rate of confabulation in AI-generated life writing.
  - 来源：ArXiv CS AI (rss.arxiv.org) · 重要性：★★★☆☆

- [A survey detection channel overrides the pixels in an astronomical foundation model, and biases tomographic mean redshifts](https://arxiv.org/abs/2608.23626)
  - 摘要：Researchers audited AION-1, a 39-modality transformer trained on more than 200 million astronomical objects. They found that holding image tokens byte-identical and editing only the survey segmentation map changes every reported quantity (flux, size, ellipticity, redshift) by 110-4400 times a matched placebo.
