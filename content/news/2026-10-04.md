  - 摘要：A USENIX FAST 2018 paper on protocol-aware recovery techniques for consensus-based storage systems. The research explores how understanding protocol semantics can improve recovery speed and correctness in distributed storage.

- [Our RISC-V emulator PasRISCV](https://againstallodds.games/blog/2026/10/03/our-risc-v-emulator-pasriscv/)
  - 摘要：An indie game studio shares details about PasRISCV, the RISC-V 64-bit emulator running inside their game SEEDS. The emulator runs Alpine Linux and executes native ELF binaries on any platform, including Windows.

- [The complement of true is true, except when it's false](https://dryperspective.github.io/posts/complement-of-true/)
  - 摘要：A deep exploration of surprising C++ boolean conversion behavior caused by integral promotion and undefined behavior on unscoped enums. The article examines a C++26 bitmask annotation proposal and its implications.
  - 来源：Lobsters · 重要性：★☆☆☆☆

- [Improving and Stabilizing the racoon2 IKE Daemon in NetBSD](https://blog.netbsd.org/tnf/entry/gsoc2026_racoon2)
  - 摘要：A Google Summer of Code 2026 project report on modernizing the racoon2 IKE daemon for NetBSD. The work includes proper NAT traversal for IKEv1 and IKEv2, IPv6 support, and a unit test framework for IPsec VPN servers.
  - 来源：NetBSD Blog · 重要性：★☆☆☆☆
